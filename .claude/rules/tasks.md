# The task runner and task memory

- **Semi-live task runner check (real OpenAI + real tools, never starts Aiva)**: `cd aiva && ..\.venv\Scripts\python ..\tests\e2e_task_runner.py "<goal>" [--yes]`
- `aiva/modules/tasks.py` — `TaskRunner`: multi-step jobs in the background. `start_task` plans (one JSON call), `task_memory.decide_autonomy` picks just_do / confirm_plan / offer_options, then a plan→act→verify→repair loop reuses the voice LLM's own tool handlers out-of-band via `ToolBox` (allow-listed subset; shell only through a paused `confirm_command` + `execute_shell`; Claude Code via `terminals.start_claude(announce_done=False)` + `wait_job`, graded afterwards against THAT step on the agent's own worktree delta — a git snapshot before/after, so his uncommitted work never reads as the agent's; `read_only` steps run in plan mode (`delegate_read_only`: the planner's flag always wins; only a flagless step is read from its words, and only a whole "don't change anything" counts — a retry he asked for "outside plan mode" once went back into plan mode over "without changing any implementation files"; a look-only step's "premise" is just its `finding` unless coding is still planned after it), code-changing ones in Claude Code's `auto` mode — `terminals.execute_permission_mode()`, `AIVA_CLAUDE_PERMISSION_MODE` auto|acceptEdits, deliberately no bypass — because headless acceptEdits denied every git/pytest command; each job gets `--effort` from the PURE `job_effort` (the planner's `action.effort` low|medium|high|xhigh, a look capped at high, one level up per partial/bad job on that project in the task; `AIVA_CLAUDE_EFFORT` auto|level|inherit — without it every job inherited his own xhigh), and a question about a few files is her own look tools, never a job (each costs a fixed ~$0.25); a project_dir that is his whole home (`.`, `~`) is re-planned and refused by `start_claude`, and the planner brief carries `your_own_code` = the repo). **One coding goal = one job**: `one_job_per_project` merges back-to-back delegate steps on one project; a later job on the same project in the same task `--resume`s that Claude session (else it gets the previous report); a repair re-run is judged against the step's FIRST snapshot. Git for these snapshots goes through `run_git` (whole output) — never `execute_shell`, which keeps the last 1000 chars and once hid every edit in a ~2,500-char status. **She runs the project's tests herself** around an execute job (`project_test_command`: the project's own `.venv` pytest only, never a model-written command; before the first job + after; failures cap the grade at partial unless already failing before; `AIVA_TASK_RUN_TESTS`, `AIVA_TASK_TEST_TIMEOUT_S`). **Second thoughts** (`_rethink`, ≤`AIVA_TASK_MAX_RETHINKS` per task): a failed/blocked delegate step's full report goes through `RETHINK_PROMPT_T` → learned facts (evidence must appear verbatim in the report — `task_memory.found_in`), retire the old facts they disprove (`Memory.retire_fact`, project/work/other/learned only), `self_lesson`, then re-plan with a corrected goal or ask him the agent's question. Keep reports head+tail (`clip_middle`) — tail-only once hid "there is no Miso renderer" — and never cut a report again after `clip_middle` (a `[:4000]` on top of it ended an 11k README review mid-word, graded "truncated" and rerun four times); the grader and rethink see `JUDGE_REPORT_CHARS` (20k), a cut says "[… N characters left out here …]", a plan-mode job's `agent_changed` is always empty (what changed meanwhile is `changed_by_others_meanwhile`), and the done note carries the report itself. Reports only through `announce()` notes (throttled milestones, questions, done/failed). `Limits` caps steps/calls/cost/time. Voice-facing tools: `start_task, answer_task, task_status, cancel_task, run_flow, task_feedback, save_flow` (`tools.make_task_handlers`).
- `aiva/modules/task_memory.py` — `TaskMemory` on `Memory.conn`: `tasks` (one row = live task state + learning episode: outcome, grade, feedback, correction flag, embedding), `flows`, `approach_preferences`. `familiarity()` (text-embedding-3-small cosine with lexical Jaccard fallback; levels routine/seen/attempted/similar/novel), the pure `decide_autonomy()`, flow candidates/replay records, preference streaks → durable facts, `grade_agent_work`, `extract_feedback` at shutdown, `load_flows`/`load_lessons` prompt blocks.
