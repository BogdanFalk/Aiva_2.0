# Web, her space, spend caps, ntfy, metrics

- `aiva/modules/web.py` — her **reach to the internet** (provider-agnostic, dependency-injected so it's fully offline-testable). `WebConfig.from_env()` + `WebClient(cfg, get=, post=)`: `search(query, kind=info|images|videos)` (Tavily `/search`, `include_images` for images), `extract(url)` (Tavily `/extract`, else `requests`+stdlib HTML strip), and the security-critical `download(url, dest_dir)` — content-type allow-list (image/ text/ pdf/ mp4 only), size cap (`AIVA_WEB_MAX_MB`), timeout, filename **extension derived from the content-type not the URL** (an executable can never be written), sha256, never executed. All methods are SYNC/blocking (mirrors `utilities.get_weather`); tool handlers wrap them in `asyncio.to_thread`. Config: `TAVILY_API_KEY`, `AIVA_WEB_SEARCH`, `AIVA_WEB_PROVIDER`, `AIVA_WEB_MODEL`, `AIVA_WEB_MAX_MB`. Tests: `tests/test_web.py` (fake `get`/`post`; asserts the safety rejections). **She finds and shows — there is deliberately no buy/sign-in/send tool anywhere.**
- `aiva/modules/space.py` — her **curated "space"** for things she gathers from the web, mirroring the book library. `SpaceMemory(memory.conn, embed=…)` owns a `finds` table (id, `sha256 UNIQUE`, kind image|video|text|link|file, subject, why, source_url, path, tags, status kept|dropped, embedding, meta_json); `save_find` (dedupe by sha256 then by **subject** embedding, cosine 0.86 / jaccard 0.60 fallback), `recall` (embedding + lexical), `drop_find` (permanent veto), `status()`/`status_lines()`. Files live under `aiva/space/` (`AIVA_SPACE_DIR`), reachable by both the engine and the home-fenced `file_operations.open_file`. Reuses `cosine`/`jaccard`/`pack_vec`/`normalize_goal` from `task_memory`. Voice tools (`tools.make_web_handlers`/`register_web_tools`): `search_web, read_page, look_at_image` (→ `computer.describe_image`, the refactored bytes/URL vision helper), `save_to_space, hand_over` (open file + speak link), `space_status, recall_from_space, drop_from_space`; the read-only ones are in `RUNNER_TOOL_ALLOW` so "go find me X" runs as a task. Persona: the "Finding things online, and your space:" section + the "YOUR SPACE" block (`build_system_prompt(space=…)`). Dashboard: "Her space" panel. Wired in `main.py` (folder-at-boot + `WebClient` + `SpaceMemory` + `_summarize_page` on `label="web"`). `python -m modules.space --show` audits. Tests: `tests/test_space.py`.
- `aiva/modules/notify.py` — **off-device push via ntfy** so a spend cap can't hit silently. `Notifier(NotifyConfig.from_env(), post=)` (injectable poster) → `notify`/`notify_async` POST to `NTFY_URL/NTFY_TOPIC`; no-op when unconfigured; Title forced ASCII, emoji via ntfy `tags`. Config `NTFY_TOPIC`/`NTFY_URL`/`AIVA_NTFY`. Tests: `tests/test_notify.py`.
- `aiva/modules/limits.py` — **per-service spend caps + pause registry** (`ServiceLimits` on `Memory.conn`). NO global $ budget by design (user decision): each service capped at its own budget/free-tier — `tavily` monthly (`AIVA_TAVILY_MONTHLY_CAP`, default 1000) is a PAUSING service; `tts`/`stt` (`AIVA_TTS_MONTHLY_CHARS`/`AIVA_STT_MONTHLY_MINUTES`, off unless set) are alert-only (pausing them would mute her). `allow(service)` gate, async `record(service, amount)` (increments `service_usage` keyed by `period=YYYY-MM` → auto-reset; fires a one-shot ntfy at ~80% and 100% via the injected Notifier; pauses a PAUSING service at cap), `is_paused`/`paused_reasons`/`usage_report`. Wired: web tool handlers + `_act_on_wish` call `allow("tavily")`/`record`; dashboard "Limits & what's paused" panel reads the tables. Tests: `tests/test_limits.py`.
- `aiva/modules/metrics.py` — operations profiler. A `metrics` table on `Memory.conn` + module-level `record()`/`span()` that no-op until `set_recorder()` at boot. Written at chokepoints only (never per audio frame): `openai_llm_call(client, model, label=)` records `llm.<label>` (task/reading/synth/self) with tokens+cost; `tools._timed` wraps every registered handler → `tool.<name>`; `_becoming_llm` uses `span("llm","becoming")`; `MicController` records `turn.latency` (user's final transcript → BotStartedSpeaking = felt latency). Rows pruned to 30 days. The dashboard's Statistics section rolls up by system.op (count/mean/max/total/share/cost) over the last 7 d. Voice-model token/cost still comes via pipecat `MetricsFrame` → `UsageTracker` (session summary), not this table.
