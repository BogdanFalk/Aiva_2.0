## How to use this file

- Each item has an **ID**, a **Status** and a **Done when** line. Change the status in place
  and add a dated line to the **Status log** at the bottom. Don't delete items. Close them with
  a reason.
- Status values:
  - `todo`: not started
  - `doing`: someone is on it
  - `blocked`: needs Frank (a live run, a decision, a key)
  - `done`: the "done when" condition was met. Cite the evidence (test name, log line, commit).
  - `wontdo`: closed deliberately. Say why.
- Priority: **P0** = a known defect or a promise the code doesn't keep. **P1** = shipped but
  never checked live, or a big module with thin tests. **P2** = planned work, hygiene, nice to
  know.
- Do **not** start, stop or restart the house or the sisters to tick an item (CLAUDE.md).
  Items marked *live* are Frank's to run. Agents verify offline: tests, the dashboard
  `--once`, offscreen renders, and the logs.
